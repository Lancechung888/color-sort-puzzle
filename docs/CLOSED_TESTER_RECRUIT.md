# Closed tester recruit pack · ColorTube Sort

EN-first. Goal: recruit **≥12 real opted-in** closed testers and keep them for **≥14 consecutive days** so a personal Play developer account can unlock Production. This is **not** a soft-launch and **not** a Production publish.

> **Landing Copy invite:** `docs/index.html` has one-tap **Copy invite (EN)** / **Copy invite (繁中)** buttons that clipboard the Short EN / Short 繁中 paste texts below (same closed URL + Become a tester steps). Keep honesty rules; do not invent testers; Prefer closed Alpha URL over internal.

## What to ask friends to do

1. **Join the tester list** (email must be on the closed Alpha list — ask the owner if you are not sure).
2. Open the **closed** opt-in URL on an Android device (signed into that Google account):
   - Closed Alpha (prefer — starts the Production-access clock):
     `https://play.google.com/apps/testing/com.lancechung.colortubesort`
3. Tap **Become a tester** (or Accept). **Listed ≠ opted-in.** Being on the list alone does **not** count.
4. Install ColorTube Sort from the Play link shown after opt-in.
5. **Open the app once** so the install/opt-in sticks.

## URLs — internal vs closed

| Track | URL | Use for |
|-------|-----|---------|
| **Closed Alpha** (prefer) | `https://play.google.com/apps/testing/com.lancechung.colortubesort` | Production-access clock (≥12 opted-in × ≥14d) |
| **Internal** (different) | `https://play.google.com/apps/internaltest/4701709602422954921` | Small internal / license QA only — does **not** replace closed Alpha |

Prefer the **closed Alpha** URL when recruiting for the Production unlock. Internal opt-in is a different track.

## Honesty rules

- **Listed ≠ opted-in.** Friends must tap Become a tester.
- **Mid-period opt-out resets the 14-day clock** for that tester (and can break the ≥12 concurrent count).
- **Open testing** needs Production access first — do not claim Open testing / public listing is live.
- **Do not invent fake tester emails.** Only recruit real people who will install and stay opted in.
- Product gates are **9 Pass**; this pack only unblocks store-access recruitment. Production remains blocked until 12×14d is real.
